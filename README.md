# TOCAS_13aMa — Structural Matrix Lab

Aplicación web académica para el análisis matricial de armaduras planas 2D mediante el método de rigidez directa.

## Funciones principales

- Editor de nodos y coordenadas.
- Definición de barras con área `A` y módulo de elasticidad `E` independientes.
- Cargas nodales y restricciones por GDL.
- Visualización interactiva de la armadura.
- Matriz de rigidez local y global por elemento.
- Grados de libertad de cada barra.
- Ensamblaje de la matriz de rigidez global.
- Vector global de fuerzas.
- Separación de GDL libres y restringidos.
- Solución de desplazamientos.
- Reacciones en apoyos.
- Deformación unitaria, esfuerzo y fuerza normal por barra.
- Clasificación visual de tracción y compresión.
- Gráfica de la deformada con escala editable.
- Ejemplo 01 y Ejemplo 02 integrados.
- Exportación a PDF, Excel y JSON.
- Importación de modelos JSON.
- Modo claro / oscuro.
- Interfaz responsive para laptop, tablet y móvil.
- Registro e inicio de sesión académico mediante almacenamiento local.

## Uso

Abre `index.html` en un navegador moderno o publícalo mediante GitHub Pages.

> El login incluido es demostrativo y local. Para usuarios reales se recomienda conectar Firebase Auth, Supabase Auth o un backend propio.
